Tools, code and collaborations built for music-technology education.


  • sinentropy (2026) — a tiny text-based language for additive synthesis in the browser (oscillators, envelopes, modulation, spectral entropy), used as a teaching example for Informatica Musicale
  • Great Eugenio (2020) — Csound / Arduino. Embedded sine-wave granulator on Raspberry Pi, controlled through a serial connection to an Arduino fitted with physical controls for the synthesis parameters, dedicated to Maestro Eugenio Giordani
  • Tutorials & code repositories — example code and tutorials for SuperCollider, Csound and Csound-Max, published on GitHub
  • Sonification for chemistry education (2012–2018, with Prof. Teresa Cecchi, ITIS Montani, Fermo) — three sonification/modelling tools used in secondary-school chemistry teaching: a 2012 tool built on the theoretical workings of chromatographic analysis, to demonstrate art–science interdisciplinarity; HPLC chromatographic data mapped to frequency bands (2018); and a Briggs–Rauscher chemical-oscillator sonification for teaching antioxidant processes (2017)
